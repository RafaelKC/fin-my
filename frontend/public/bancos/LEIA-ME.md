# Logos de bancos

SVGs de <https://github.com/rzmt/logos-bancos-br> (código MIT), nomeados pelo código COMPE. Os logos são **marcas
registradas das instituições**, não cobertos pela licença do repositório de origem nem deste; usados apenas para
identificar o banco de uma carteira ou cartão (uso nominativo), sem alteração. Ver o
[DISCLAIMER](https://github.com/rzmt/logos-bancos-br/blob/main/DISCLAIMER.md) de origem.
